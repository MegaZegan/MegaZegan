## Featured Security Projects

| Project | What it does | Best part |
| --- | --- | --- |
| [VaultWatch-Terminal](https://github.com/MegaZegan/VaultWatch-Terminal) | Fallout/Pip-Boy inspired local telemetry triage for JSONL, JSON, and CSV logs. | Security dashboard energy without touching real production data. |
| [TraceLens](https://github.com/MegaZegan/TraceLens) | CLI for suspicious authentication, firewall, DNS, and outbound traffic patterns. | Finds patterns that make analysts say "wait, scroll back up." |
| [SentinelForge](https://github.com/MegaZegan/SentinelForge) | SOC analytics toolkit with normalization, detections, risk scoring, and HTML reports. | A report generator that tries very hard to be useful on purpose. |
| [CloudPolicyLens](https://github.com/MegaZegan/CloudPolicyLens) | IAM-style cloud policy linter for risky permissions and weak guardrails. | Points at dangerous wildcards with the calm confidence of a lint tool. |
| [SecretHawk](https://github.com/MegaZegan/SecretHawk) | Local defensive secret scanner with masked findings, entropy checks, and SARIF output. | Keeps secrets secret, which is refreshingly on brand. |
